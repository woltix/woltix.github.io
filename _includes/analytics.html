{%- comment -%} =========================================================================== Google Analytics 4 via Google Consent Mode v2. Why it is built this way ------------------------ The previous setup loaded gtag.js in but only ran gtag('config', …) inside the cookie banner's accept branch. Visitors who never clicked "Approve" — the large majority — were therefore never counted at all, and the accept path then called location.reload(), so the one pageview that did fire was attributed to a reload. That is why the numbers looked broken. Now: consent defaults are declared DENIED *before* gtag.js loads, so no analytics cookie and no identifier is written until the visitor opts in. Google still receives cookieless, non-identifying pings it can use for modelled traffic, and the moment consent is granted the tag upgrades in place — no reload, no lost pageview. Set analytics.ga4_id to "" in _config.yml to remove analytics entirely. =========================================================================== {%- endcomment -%} {%- if site.analytics.ga4_id and site.analytics.ga4_id != "" -%} {%- endif -%}
