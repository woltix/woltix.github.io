The platform

Four products
on one data model

Each product solves a problem on its own. Start with the one you need most; add the others when you are ready.

Core

Portfolio Management

Portfolio 360 — every position, currency and asset class in one view, with the structure, risk and rebalancing analysis to act on it.

  • Real-time positions and value walk in your reporting currency
  • P&L split into realised, unrealised, coupons, dividends, derivatives margin and fees, and attributed to each holding
  • Structure by asset class, currency, issuer, country, industry or your own categories, against model
  • Value at Risk (Monte-Carlo, parametric, historical) down to holding level
  • Return forecasting and rebalancing with pre-trade impact
Feeds the core

Portfolio Consolidation

Reads the files your custodians and fund administrators send — spreadsheets, CSV exports, custodian formats, API feeds — and turns them into one clean set of positions.

  • Format mapping per custodian, set once and reused
  • Anonymized upload, no client identifiers required
  • Position and transaction reconciliation on load
  • Output to Portfolio Management, Reporting or your own systems
Feeds the core

Market Data

One valuation layer across listed and unlisted holdings. Bring your own vendors, or use ours — and value what the vendors don’t cover.

  • Multi-source pricing, FX and corporate actions
  • Priority and fallback rules between sources
  • Valuation of real estate, private equity and structured notes
  • Also available on its own, via API
Built on the core

  • Scheduled, branded, automatic delivery

Custom flows

Your process,
built and run by us

A new flow is configured on the platform, not built from scratch. We design it with you, put it into production and keep it running.

Firms rarely need “a portfolio system”. They need a specific obligation met, on schedule, in a format someone else dictates. That is what we build, on top of the platform.

  • Data contribution — constituent and NAV files to market data providers and platforms.
  • Regulatory submissions — filings assembled from the same book, on the reporting calendar.
  • Client and board packs — branded, scheduled, per mandate or per household.
  • Mandate and risk monitoring — breach checks that run daily and escalate to the right desk.
  • Onboarding and migration — historical positions and transactions loaded from a legacy system.
  • Outbound integrations — feeds to accounting, CRM, order management and your own tooling.

Each flow is set up once — sources, mappings, schedule, recipients — then runs unattended, with our support behind it.
